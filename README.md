# MICAS-Design

MICAS-Design 是一个面向 MasterGo 画布的 AI 视觉设计插件，目标是把图片生成、参考图编辑、常用画布操作和本地图片处理集中到同一个工作流中。

> 项目仍在持续开发中。当前开发里程碑已经推进到 **快速抠图**：可在本地识别白色或近白色背景，生成透明 PNG，并将结果插入原图右侧。后续功能会继续更新和完善。

## 已实现功能

### AI 图片生成与编辑

- 支持文字生成图片和参考图编辑。
- 最多可添加 10 张参考图。
- 参考图可以标记为产品、模特、场景、姿势、风格、发型、妆容、构图、色调等角色。
- 支持原图自适应及 `1:1`、`2:3`、`3:4`、`4:5`、`16:9`、`9:16` 等常用比例。
- 支持 `1K`、`2K`、`4K` 分辨率选项，实际可用范围取决于所选模型。
- 生成结果可以保存到记录、下载或插入 MasterGo 画布。

### 模型与接口配置

插件采用 BYOK（Bring Your Own Key）方式配置图片模型接口，当前界面预设包括：

- GPT Image 2
- Nanobanana 2
- Nanobanana Pro
- Seedream 5

同时支持预设服务和 OpenAI Compatible 接口。模型是否可用、支持的尺寸及计费方式以对应服务提供方为准。

### 设计辅助能力

- AI 提示词润色。
- 个人提示词库。
- 风格库与场景裂变、城市街拍、搭配提取等预设 Agent。
- 智能扩图：调整目标画布比例和主体位置后补全场景。
- 万物上身：以人物为底图，添加主商品和搭配商品完成换装。
- 九宫格裁切：把选中图片等分为 9 个独立画布图层。

### 资产库

- 独立页面管理品牌素材、模特图片和搭配成片。
- 生成记录和画布选中图片均可通过分类选择加入资产库。
- 资产可再次设为参考图、插入 MasterGo 画布或删除，并通过 `clientStorage` 持久保存。

### 快速抠图

快速抠图是当前最新完成的功能，定位是一个轻量、快速、无需模型调用的本地工具。

- 不调用 AI，不消耗 API Key。
- 自动估算画布边缘的白色或近白色背景。
- 只移除与画布边缘连通的背景区域，降低误删主体内部白色区域的概率。
- 背景像素 Alpha 设置为 `0`，输出透明 PNG。
- 保留主体原始 RGB 与不透明像素，并在边缘加入轻量羽化。
- 支持常见的人像或商品贴近画布边缘的构图。
- 完成后将透明 PNG 插入原图右侧，同时保留原图。
- 对非白底、复杂场景或无有效背景的图片会停止处理，不会自动转入 AI 生成。

说明：纯像素算法无法可靠区分“颜色完全相同且直接相连”的白色主体与纯白背景。建议输入具有可见轮廓、阴影或轻微色差的白底人像/商品图。

## 本地开发

### 环境要求

- Node.js 18 或更高版本
- npm
- MasterGo 桌面端或支持本地插件调试的环境

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

该命令会同时监听 UI 和插件主线程代码的变化，并持续更新 `dist` 目录。

### 构建

```bash
npm run build
```

构建完成后会生成：

- `dist/index.html`：插件 UI
- `dist/main.js`：MasterGo 插件主线程

在 MasterGo 本地插件调试中导入项目根目录的 `manifest.json` 即可加载。

### 测试与类型检查

```bash
npm test
npm run typecheck
```

快速抠图测试覆盖白底、近白底、JPEG 噪点、透明 PNG、边缘羽化、多人主体、贴边主体、复杂背景和重复任务等场景。

## 项目结构

```text
MICAS-Design/
├─ lib/                 # MasterGo 插件主线程与画布操作
├─ messages/            # UI 与主线程的消息类型
├─ ui/
│  ├─ components/       # React 界面组件
│  ├─ engine/           # 模型注册、适配器与生成引擎
│  └─ utils/            # 快捷操作和本地图片处理
├─ tests/               # 自动化测试
├─ scripts/             # 测试及辅助脚本
├─ dist/                # 可加载的构建产物
├─ manifest.json        # MasterGo 插件清单
└─ vite.config.ts       # UI/主线程双目标构建配置
```

## 使用建议

1. 在设置中配置自己的模型服务和 API Key。
2. 选择生图或改图模式，输入描述并按需添加参考图。
3. 选择模型、比例、分辨率和输出数量后开始生成。
4. 对画布中的图片，可开启“快捷栏”直接使用九宫格、扩图、万物上身或快速抠图。
5. 使用快速抠图时，优先选择背景均匀、主体轮廓清晰的白底图片。

请勿把 API Key、图床凭证或其他私密配置提交到 Git 仓库。
